# Computer Organization 2026-27 at UCM
This is a second-year course in the Computer Science degree program offered at UCM. You can see the contents of this course at [Computer Organization UCM](https://web.fdi.ucm.es/UCMFiles/pdf/FICHAS_DOCENTES/2026/9512.pdf).

The theoretical part of the course begins with a review of the foundational concepts introduced in the first‑year Computer Fundamentals course, covering the RISC‑V architecture, assembly programming, and the single‑cycle, multi‑cycle, and pipelined processors presented in Harris & Harris. Building on this basis, the VeeR EH1 pipelined processor is used to introduce advanced microarchitectural techniques such as deep pipelining, superscalar execution, and multi‑cycle operations. The course then examines the memory hierarchy in detail, including cache organization and virtual memory, emphasizing their impact on system performance and design. It also explores a generic I/O subsystem, addressing programmed I/O and interrupt‑driven I/O. Finally, the course includes a brief overview of IEEE 754 floating‑point arithmetic and selected topics on emerging architectural trends and modern data processing centers.

The course includes five labs:

+ [Lab 0](https://github.com/artecs-group/RVfpga-sim-addons/tree/main/Computer_Organization_25-26/Lab0): Introduction and Installation.
+ [Lab 1](https://github.com/artecs-group/RVfpga-sim-addons/tree/main/Computer_Organization_25-26/Lab1): The RISC-V ISA.
+ [Lab 2](https://github.com/artecs-group/RVfpga-sim-addons/tree/main/Computer_Organization_25-26/Lab2_25-26): The Ripes core and the VeeR EH1 core.
+ [Lab 3](https://github.com/artecs-group/RVfpga-sim-addons/tree/main/Computer_Organization/Lab3): The Memory Hierarchy.
+ [Lab 4](https://github.com/artecs-group/RVfpga-sim-addons/tree/main/Computer_Organization/Lab4): The RVfpga I/O System.

In this course, we do not have boards available for all students (ranging from 50 to 80 per year). Therefore, all labs are conducted through simulations using tools such as RVfpga-ViDBo, RVfpga-Pipeline, and Ripes, within a provided Virtual Machine.
